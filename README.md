# KrishaParser

Ищет на krisha.kz квартиры, которые дешевле своих аналогов, и строит отчёт `report.html`
с разбивками по цене, году постройки и локации, фильтрами и сортировками.

Идея: обычный код собирает объявления и считает цифры, а ИИ смотрит фото и сверяет их
с тем, что написал продавец (ремонт, мебель, техника).

## Как это работает

| Этап | Команда | Что делает |
|---|---|---|
| Сбор | `run.py collect` | проходит страницы списка по вашей ссылке, пишет объявления в базу, следит за изменением цен и снятыми объявлениями |
| Расчёты | `run.py enrich` | склеивает копии одной квартиры, подбирает аналоги, считает скидку |
| Фото | `run.py photos` | качает фото напрямую с фотосервера |
| Оценка ИИ | `run.py vision` | уровень отделки, мебель, техника, расхождения текста и фото |
| Отчёт | `run.py report` | собирает `report.html` |

`run.py` без аргументов делает сбор, расчёты и отчёт подряд.

## Установка

Нужен Python 3.10+.

```
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
```

## Настройка

Всё в `config.yaml`:

- **`search_url`** — ссылка с krisha.kz, прямо из адресной строки (с карты или из списка).
  Фильтры и границы поиска берутся из неё.
- **`collector`, `photos`** — паузы и лимиты.
- **`llm`** — какой ИИ использовать на каждом этапе.
- **`buckets`, `comps`** — корзины для разбивок и пороги для аналогов.

## Подключение ИИ

Два способа, переключаются в `config.yaml`:

- **`claude_cli`** — Claude по подписке, без покупки API. Нужен установленный Claude Code
  и один раз выполненный вход: `claude auth login`.
- **`openai_compatible`** — любой сервис с OpenAI-совместимым API (Gemini, Groq, OpenRouter,
  локальная Ollama). В конфиге задаются адрес, модель и имя переменной окружения с ключом.

Свой провайдер добавляется одной функцией в `krisha/llm.py`.

## Запуск

```
.venv\Scripts\python run.py            сбор + расчёты + отчёт
.venv\Scripts\python run.py photos     скачать фото (photos 20 — только для 20 квартир)
.venv\Scripts\python run.py vision     оценка фото ИИ (vision 5 — только для 5 квартир)
.venv\Scripts\python run.py stats      сводка по базе
.venv\Scripts\python -m unittest discover tests
```

Любой этап можно прервать: при следующем запуске он продолжит с места остановки.

## Где что лежит

| Файл | Что делает |
|---|---|
| `config.yaml` | все настройки |
| `run.py` | точка входа, команды |
| `krisha/collector.py`, `parse.py` | сбор и разбор страниц списка |
| `krisha/db.py` | таблицы SQLite |
| `krisha/enrich.py` | копии, аналоги, скидка |
| `krisha/photos.py` | загрузка фото |
| `krisha/llm.py` | единая точка обращения к ИИ, провайдеры |
| `krisha/vision.py` | оценка фото и сверка с текстом |
| `krisha/report.py`, `report_template.html` | отчёт |
| `CLAUDE.md`, `AGENTS.md` | правила проекта для ИИ-помощников |
| `data/` | база и фото (создаётся сама, в репозиторий не попадает) |

## Известные ограничения

- Карточки объявлений закрыты проверкой на бота, и проект её не обходит. Поэтому нет
  полного описания (в списке оно обрезано примерно до 300 знаков) и координат.
- Цены — из объявлений, не из сделок.
- Склейка копий — эвристика: тот же дом, комнаты, площадь, этаж и цена в пределах 7%.
- Инструмент для личного использования. Соблюдайте правила krisha.kz и не повышайте частоту запросов.
