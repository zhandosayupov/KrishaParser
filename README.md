# KrishaParser

Ищет на krisha.kz квартиры, которые дешевле своих аналогов, и строит отчёт `report.html`.

## Запуск

```
.venv\Scripts\python run.py            всё сразу: собрать, посчитать, построить отчёт
.venv\Scripts\python run.py collect    только собрать объявления в базу
.venv\Scripts\python run.py enrich     дубли, аналоги, скидки
.venv\Scripts\python run.py report     построить report.html
.venv\Scripts\python run.py stats      сводка по базе
.venv\Scripts\python -m unittest discover tests    проверки разбора страниц
```

Настройки (ссылка поиска, паузы, корзины, пороги) — в `config.yaml`.

## Где что лежит

| Файл | Что делает |
|---|---|
| `config.yaml` | настройки: ссылка с фильтрами и границами, паузы, корзины |
| `krisha/config.py` | читает настройки, превращает ссылку с карты в адрес списка |
| `krisha/collector.py` | проходит страницы списка с паузами, пишет в базу |
| `krisha/parse.py` | достаёт поля объявления из страницы списка |
| `krisha/db.py` | таблицы SQLite: объявления, история цен, проходы |
| `krisha/enrich.py` | склейка копий, класс отделки, подбор аналогов, скидка |
| `krisha/report.py` + `report_template.html` | сборка отчёта |
| `data/krisha.sqlite` | база (создаётся сама) |

## Известные ограничения

- Данные берутся только со страниц списка. Карточки объявлений закрыты проверкой на бота,
  поэтому нет полного описания (в списке оно обрезано примерно до 300 знаков), всех фото и координат.
- Отделка пока определяется со слов продавца, по фото не проверена.
- Цены — из объявлений, не из сделок.
