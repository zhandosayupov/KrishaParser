Квартиры: сравнение с аналогами

Скидка — насколько цена за м² ниже медианы аналогов. Аналоги ищутся по шагам: тот же ЖК с той же отделкой → тот же ЖК → рядом (район, тип дома, годы, площадь ±20%, отделка) → район. Отделка пока взята со слов продавца, по фото не проверена. Цены — из объявлений, не из сделок.
